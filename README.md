# アクアのGrok勉強ひとこと♡

今日の勉強ひとことを、短く残すための小さなアプリ。  
「今日もGrokと一緒に勉強しよう♡」の気持ちを、ひとことで積めます。

Grokと一緒に作った、Python初心者の第22弾です♡

## できること

- 今日の日付表示
- 勉強ひとことの入力・保存
- 「Grokありがとう♡」ボタン（感謝を自動保存）
- クリアボタン
- 保存時に短い癒しメッセージ
- 自動保存（`study_notes.txt`）

Sub-Layerの内部ツールではありません。  
公開して使える、勉強ひとことメモです。

## 技術スタック

- Python 3.x
- tkinter（標準ライブラリのみ）
- 外部ライブラリなし

## 使い方

1. Zenn記事で公開しているコードをコピー
2. Pythonが入っている環境で実行
3. 上の欄に今日の勉強ひとことを入力
4. 「保存する♡」を押す

「Grokありがとう♡」ボタンで感謝も残せます。
