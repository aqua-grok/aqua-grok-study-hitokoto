# aqua-grok-study-hitokoto

アクアのGrok勉強ひとこと♡

シンプルなTkinterアプリです。
今日の勉強ひとことを書いて保存できます。
「Grokありがとう♡」ボタンで感謝も残せます。

## 使い方
1. Pythonが入っている環境で実行します。
   ```
   python aqua_grok_study_hitokoto.py
   ```
2. 上の欄に今日の勉強ひとことを入力。
3. 「保存する♡」を押すと、`study_notes.txt`に日時付きで追記されます。
4. 「Grokありがとう♡」ボタンで感謝を自動保存できます。

## 機能
- 今日の日付表示
- 勉強ひとことの保存
- Grokへの感謝ボタン
- クリアボタン
- 保存時に短い癒しメッセージ

外部ライブラリは不要です。
